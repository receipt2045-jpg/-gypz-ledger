# 줄글·음성 고백 설계

2026-08-01 · 브레인스토밍 결과 (사용자 위임: "알아서 해")

## 목적

고백을 "카테고리 탭 → 금액 탭" 반복에서 **한 번에 여러 건을 말/글로 입력**하는 방식으로 바꾼다.
예: "점심 김밥 9천원, 커피 5,500원, 택시 12,000원" → 3건 파싱 → 확인 → 저장.

## 핵심 제약 (조사 결과)

- **iOS 홈화면 PWA에서는 Web Speech API가 동작하지 않는다** (Safari 브라우저에선 됨).
  → 마이크 버튼은 **되는 환경에서만** 보여주는 보너스. 기본 입력은 **텍스트**이고,
  iOS 사용자는 OS 키보드의 딕테이션(마이크 키)으로 같은 경험을 얻는다. 이 방식은 PWA에서도 동작한다.
- 파싱은 **전부 로컬 순수 함수**. LLM 호출 없음 (비용 0, 오프라인 동작, ai-coach 같은 보안 문제 없음).

## 구조

### 1) `src/lib/confessParser.ts` — 순수 함수 (테스트 대상)

```
parseConfessionText(text, categories, aliases) → { entries: ParsedEntry[], unmatched: string[] }
ParsedEntry = { category, kind, amount, note?, raw }
```

- 구분자: 쉼표, 줄바꿈, "…원 " 뒤 공백, '그리고'.
- 금액: `12,000원`·`9천원`·`1만2천`·`3만`·`만원`·`5500` 지원. 순한글 숫자(구천원)는 1차 제외.
- 카테고리 매칭: ① 사용자 카테고리명 직접 포함 → ② 별칭 사전(내장+학습) → ③ 실패 시 `변동지출/기타` + 원문을 note로.
- 내장 별칭 예: 김밥/점심/저녁→식비, 커피/스벅→카페, 택시/주유→자동차, 넷플→구독, 영화→문화생활 등.

### 2) 별칭 학습 — `households.category_aliases` jsonb

확인 화면에서 카테고리를 고치면 `{ "김밥": "식비" }` 형태로 가구 단위 저장(부부 공유). 다음부터 자동 매칭.

### 3) 화면 — `Confess.tsx` 3단계

1. **입력**: textarea + (지원 환경만) 인앱 마이크 버튼(`ko-KR`, 최종 결과를 textarea에 덧붙임).
   기존 버튼식 입력은 "버튼으로 고르기" 링크로 유지 (초보자·파싱 실패 대비).
2. **확인**: 파싱된 항목 리스트. 항목별 카테고리 수정(수정 시 별칭 학습)·금액 수정·삭제. "N건 고백하기".
3. **반응**: 기존 반응 화면 재사용. 여러 건이면 **reduce 버킷 중 최고액 1건**을 저격 대상으로 pickReaction.

### 4) 저장

기존 `addConfession`을 건수만큼 호출 (낙관적 로컬 + 큐 재사용, 서버 스키마 변경 없음 — 별칭 컬럼만 추가).

## 범위에서 뺀 것 (YAGNI)

- 순한글 숫자 파싱, LLM 파싱 폴백, 날짜 지정("어제 커피"), 수입/저축 자동 인식(변동·고정지출 중심).

## 검증

- vitest로 파서 단위 테스트 (금액 표기 6종 × 매칭 3경로 × 다건 분리).
- `tsc -b` 통과, 실 기기 확인은 배포 후.
